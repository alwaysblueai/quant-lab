后端迭代优先

模糊 model idea 的初步探索、草稿实验和下一轮点评默认在 Codex GUI 后端完成；本页面只接收已经迭代到较成熟的 `model_candidate_payload`，用于标准验证、完整报告和 artifact 可视化。新 idea 请先在终端跑 alpha-lab model-idea distribute --idea "..." 生成 ideas/<idea_id>/（含 generator + reviewer prompts），再把网页版 GPT 输出粘到下方。粘贴的 payload 没有 provenance.idea_id 时 validator 会发出 provenance_missing warning。

0. Stage 0 分发 终端或上方面板调用 alpha-lab model-idea distribute，产出 retrieval pack + 两份对称 engine prompts（claude / codex）。
1. 双引擎并行 Claude Code 与 Codex GUI 各自完成 generator + reviewer 合一任务；两者互不可见。
2. 网页版 GPT 迭代 把两份 Stage 1 输出 + stage2_input 模板交给网页版 GPT，产出含 provenance 的 `model_candidate_payload`。
3. 前端完整报告 候选足够成熟后，在下方 Draft Candidates 面板运行完整报告并检查审计 hash + provenance.idea_id。
