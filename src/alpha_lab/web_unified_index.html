ALPHA_LAB USER_GUIDE

前提条件 (Prerequisites)

  • 已在终端执行 alpha-lab web unified --vault-root /path/to/quant-knowledge 启动服务
  • 或设置了环境变量 OBSIDIAN_VAULT_PATH 后直接执行 alpha-lab web unified
  • vault 目录下需存在 90_moc/CARD-INDEX.tsv,卡片搜索依赖它

整体工作流 (Workflow)

  1. A. 知识库 — 搜索相关因子卡片,确认研究假设;查看 inbox 待处理文件
  2. B. 研究工作台 — 新建项目(弹窗)→ 明确 hypothesis / focus → 刷新 current case
  3. C. 工作台内验证 — 在同一页 Step 4/5 完成运行、结果解读与状态同步
  4. D. 导出台 — 仅在需要正式写回知识库时使用

A. 知识库操作

  • 卡片搜索:输入关键词(如 momentum),点击"搜索"
  • 卡片查看器:输入卡片文件名,点"读取"查看全文
  • 待处理文件:显示 00_inbox/ 中的文件

B. 工作台操作

  • 新建项目:点击侧栏或右侧 NEW_PROJECT 打开弹窗初始化
  • 状态同步:维护 hypothesis / focus / next action
  • 刷新 Current Case:填写参数生成当前实验合同

C. 工作台内验证(Step 4/5)

  • 启动实验:在 Workspace 的 Step 4 选择 current case 和 profile,后台运行
  • 查看产物:点击 artifact 链接内联查看
  • 结果解读 + 同步:在 Step 5 审阅 latest result / decision log 并回填状态

D. 审核操作

  • 审阅:只在需要正式 writeback 时查看草稿
  • 标注:填写结论和审阅状态
  • 回写:把正式结论写回知识库
